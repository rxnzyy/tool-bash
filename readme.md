# Консольная утилита Bash

Утилита предоставляет удобный интерфейс для получения списка пользователей, процессов, а также перенаправления вывода и ошибок в указанные файлы.

## Возможности

- **-u**, **--users** — вывод списка пользователей и их домашних директорий (алфавитная сортировка)
- **-p**, **--processes** — вывод списка процессов, отсортированных по PID
- **-l PATH**, **--log PATH** — перенаправление стандартного вывода в файл
- **-e PATH**, **--errors PATH** — перенаправление ошибок stderr в файл
- **-h**, **--help** — вывод справки

## Установка

### Linux / macOS

```bash
git clone <URL вашего репозитория>
cd <папка проекта>
chmod +x utility.sh
```

### Windows

Так как утилита написана на **Bash**, для Windows требуется установить среду, поддерживающую Bash:

#### Вариант 1: Git Bash (рекомендуется)

1. Скачайте и установите Git for Windows: [https://git-scm.com/download/win](https://git-scm.com/download/win)
2. Откройте **Git Bash**.
3. Выполните:

```bash
git clone <URL вашего репозитория>
cd <папка проекта>
chmod +x utility.sh
./utility.sh --help
```

#### Вариант 2: WSL (Windows Subsystem for Linux)

1. В PowerShell (от имени администратора):

```powershell
wsl --install
```

2. Установите любую Linux-дистрибуцию (Ubuntu по умолчанию).
3. Запустите терминал WSL и выполните:

```bash
git clone <URL вашего репозитория>
cd <папка проекта>
chmod +x utility.sh
./utility.sh --help
```

## Использование

### Вывести список пользователей

```bash
./utility.sh --users
```

### Вывести процессы

```bash
./utility.sh -p
```

### Записать вывод в лог-файл

```bash
./utility.sh -u -l users.log
```

### Записать ошибки в файл

```bash
./utility.sh -p -e errors.log
```

### Вывести справку

```bash
./utility.sh -h
```

## Проверка прав доступа

Утилита автоматически проверяет, можно ли записывать в указанные файлы. Если путь недоступен, выводится понятное сообщение об ошибке.


## Требования

- Интерпретатор `bash`
- Поддержка `getopt` в системе
